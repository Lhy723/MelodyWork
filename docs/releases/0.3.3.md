## MelodyWork 0.3.3

### 更新内容

- 重构客户端模块，拆分聊天、研究、设置、文件和运行时逻辑，降低后续维护成本。
- 新增并统一 Interior 交互组件，覆盖按钮反馈、搜索、加载、进度、弹出层、抽屉、模态框、Tabs、Accordion 和树形导航等场景。
- Marketplace 插件列表支持来源切换、搜索和渐进式加载，并改进插件安装、更新和来源管理的状态反馈。
- 更新器支持稳定版与测试版渠道、签名清单、下载进度和安装进度展示。
- 设置中的模型页面与范围选择改为 Tabs 布局；模型思考强度使用分段滑条；版本历史与计划报告支持折叠查看。
- 改进项目、任务、会话、文件、Git 和研究工作区的布局、操作反馈及 Subagent 展示，侧边栏项目与会话统一为树形导航。
- 统一 UI 字体、浅色/深色主题和窗口材质表现，优化按钮表面、通知位置及响应式布局。

### 修复

- 修复流式回答事件订阅、消息节点复用和逐字动效中断问题，提升长文本与中文内容的动画稳定性。
- 修复上下文用量在恢复会话后显示为 0、Subagent 状态持久化不一致及模型列表加载遗漏的问题。
- 修复 Marketplace 插件更新状态误判、来源按钮点击失效、更新结果重复提示及原生确认弹窗问题。
- 修复侧边栏树形节点展开收起、内容溢出、任务与项目层级及搜索框尺寸适配问题。
- 修复更新发布流程的版本校验、来源分支校验和 beta 更新清单发布范围。

请根据平台下载对应安装包；更新器会验证签名后提供应用内更新。
