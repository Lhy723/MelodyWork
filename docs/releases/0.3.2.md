## MelodyWork 0.3.2

### 更新内容

- 重构客户端模块，将聊天、研究、设置、文件和运行时逻辑拆分为更易维护的组件与模块。
- 优化项目与任务导航：项目和任务分组可独立展开收起，并完善工作区切换、新建任务和项目管理流程。
- 改进会话工作区布局、侧边面板、终端和会话信息展示，统计信息支持折叠，减少重复描边并统一圆角与背景层次。
- 优化 macOS 模糊透明材质、窗口布局和浅色/深色主题表现，同时保留 Windows 的纯色窗口背景。
- 改进插件 Marketplace 展示和来源管理，修复已安装插件数量与 Marketplace 内容不同步的问题。
- 更新设置页的环境检查、更新渠道和配置交互，正式版与测试版均使用统一的检查更新入口。

### 修复

- 增强 ACP 会话错误处理，对限流、重试耗尽和超时状态显示明确的完成错误，避免任务无响应。
- 修复工作区未选择时的任务启动提示、项目删除和终端交互流程。
- 修复会话面板挤压、滚动条位置、热力图方格圆角及深色模式间隙颜色等界面问题。

请根据平台下载对应安装包；更新器会验证签名后提供应用内更新。
