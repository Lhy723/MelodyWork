## MelodyWork 0.4.0-beta.1

### 更新内容

- Pi 成为唯一 Agent 会话运行时；旧 ACP 会话保留为只读归档，不作为 Pi 的运行时回退。
- 保留插件市场，并将扫描、安装、更新和卸载迁移到 Host 原生实现；移除 Melody Build sidecar 和子模块构建链路。
- 模型认证统一为直接填写 API key，并支持在应用内刷新 Pi 模型目录。
- 技能列表改为展示 Pi 实际发现的技能；扩展详情和启用状态与当前运行时目录保持一致。
- 优化侧边栏项目、任务和会话的树形层级与选中反馈；会话信息侧栏移除定时任务面板。
- 将一轮中的思考、工具活动和结果收拢为可折叠活动组，展示整轮耗时与可读的执行状态。

### 修复与稳定性

- 修复 Pi 资源刷新拒绝合法的 `read-write-execute` 子代理能力值，导致会话无法继续的问题；未知能力值仍会被拒绝。
- 改善空回复、失败回复及工具运行状态的收尾展示，避免请求完成后只留下空白或持续旋转状态。
- 修复新会话输入框在选择旧归档会话时被错误禁用的问题，并改善模型、权限等下拉控件的交互。
- 移除启动和发布流程对旧 Melody Build sidecar 的依赖，改为构建并 smoke-test Pi worker。

### 已知限制

- 这是测试版；尚未完成所有目标平台和真实 Provider 的桌面验收。未由 Pi 实现的能力会按兼容性清单提示或阻断，不会回退到旧 Agent runtime。
- macOS 构建未使用 Apple Developer ID 签名或公证；首次打开时可能需要在 Finder 或系统设置中确认。

请按平台下载对应安装包。应用内更新清单使用 Tauri updater 签名验证；该签名不替代 Apple 平台签名。
