## MelodyWork 0.3.3-beta.2

### 更新内容

- 设置中的模型页面改为 Tabs 布局，自定义模型置于第一项，并将“默认值与生成行为”独立切换。
- 设置侧栏的“应用 / 当前项目”范围选择统一为 Tabs 交互，保留配置锁定和键盘切换行为。
- 新增并统一 Interior 的下拉菜单、弹出层、抽屉、上下文菜单、模态框和 Tabs 组件，减少页面之间的交互差异。
- 优化插件、研究、会话、项目和文件工作区的操作反馈、引用展示及布局细节。
- 改进 Subagent 展示、运行统计和上下文用量持久化，提升长对话恢复后的状态一致性。

### 修复

- 修复 Marketplace 来源按钮在更新界面中的点击失效问题。
- 修复配置范围切换和模型设置在保存或加载期间的交互状态问题。

这是测试版，可能包含尚未完全验证的功能。请根据平台下载对应安装包；更新器会验证签名后提供应用内更新。
