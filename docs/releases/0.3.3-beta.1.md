## MelodyWork 0.3.3-beta.1

### 更新内容

- 重构客户端模块，拆分聊天、研究、设置、文件和运行时逻辑，降低后续维护成本。
- 新增并统一 Interior 交互组件，改善按钮反馈、搜索、加载状态、进度展示和 Marketplace 操作体验。
- Marketplace 插件列表支持按来源切换、搜索和渐进式加载，修复已安装插件更新状态误判。
- 更新器支持稳定版与测试版渠道、签名清单、下载进度和安装进度展示。
- 移除设置和插件操作中的原生确认弹窗，统一使用应用内交互反馈。
- 统一 UI 字体、浅色/深色主题和窗口材质表现，减少重复描边并优化按钮表面。
- 改进项目、任务、会话、终端和研究工作区的布局与错误提示。

### 修复

- 修复工作区未选择时的任务启动提示、插件更新结果和 Marketplace 空列表状态。
- 修复更新发布流程的版本校验、来源分支校验和 beta 更新清单发布范围。

这是测试版，可能包含尚未完全验证的功能。请根据平台下载对应安装包；更新器会验证签名后提供应用内更新。
