## MelodyWork 0.3.3-beta.3

### 更新内容

- 新增并应用 Interior 的 Accordion、Show More、Slider Detents 和 Text Reveal 组件，优化版本历史、计划报告、模型思考强度与工作区欢迎内容的交互表现。
- 改进流式回答的 Markdown 渲染与逐字揭示动效，支持中文字符、英文单词、换行、列表和代码块，并避免长文本动画队列过长。
- 优化对话时间线、研究页面、任务输入和会话面板的内容展示、加载状态及交互反馈。
- 改进模型配置、研究工作区和上下文用量的状态同步与持久化，提升长对话恢复后的显示一致性。

### 修复

- 修复 ACP 流式事件监听因会话标识更新而重复订阅，导致回答只收到前几行的问题。
- 修复流式消息在工具或思考事件后恢复时使用重复时间戳 ID，导致后续文字节点被 React 复用、动效中断的问题。
- 修复流式回答组件在动画参数变化时被 memo 错误跳过更新的问题。

这是测试版，可能包含尚未完全验证的功能。请根据平台下载对应安装包；更新器会验证签名后提供应用内更新。
