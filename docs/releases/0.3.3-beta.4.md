## MelodyWork 0.3.3-beta.4

### 更新内容

- 新增 Interior 风格的 Tree View 组件，支持嵌套展开收起、选中态、键盘导航、ARIA 属性和 reduced-motion 适配。
- 将工作区文件浏览器和 Git 变更审查改为树形结构，补充目录层级、文件图标及变更统计展示。
- 将侧边栏的项目、归档项目、任务和会话统一到同一棵树中，支持项目/任务同层级显示及展开收起动画。
- 保留项目和会话的上下文菜单、新建入口、归档操作和运行状态反馈，并改善筛选后的树节点展开行为。

### 修复

- 修复树形导航折叠时内容溢出以及侧边栏高度动画不完整的问题。
- 删除旧的项目分组实现，统一使用 Tree View 的焦点、选择和展开逻辑。

这是测试版，可能包含尚未完全验证的功能。请根据平台下载对应安装包；更新器会验证签名后提供应用内更新。
