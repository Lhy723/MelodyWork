# Scientific Writing

## 写作流程

1. 先写事实清单：数据、方法、结果、限制和来源；把推断与事实分开。
2. 用一句话说明问题和贡献，再按“主张—证据—边界”组织段落。
3. 删除空泛形容词和无来源的强断言；优先给出效果量、范围、对照和不确定性。
4. 保持术语、变量、单位、时态和引用一致；不改变原始数据或统计含义。
5. 输出修改版，并用短表格说明每个关键改动和证据来源；无法核验的句子保留警示。

## 推荐结构

- 摘要：背景/问题 → 方法 → 核心结果 → 边界/意义。
- 导读：研究问题 → 方法与数据 → 关键结果 → 局限 → 读者下一步。
- 讨论：回答问题 → 与已有证据的关系 → 可能机制 → 限制 → 可检验预测。

## 边界

- 不把“可能”“提示”“相关”改写成“证明”“导致”“普遍有效”。
- 不用语言润色掩盖样本小、单一来源、选择偏差或统计不确定性。
- 任何新增事实都必须来自用户提供的论文/数据或 Research 的核验记录。
