# Citation Audit

## 审核流程

1. 规范化 DOI、PMID、arXiv ID 和 URL，记录用户提供的原始标识。
2. 通过至少两个独立来源查找元数据；优先 Crossref/OpenAlex，再用 Semantic Scholar、PubMed 或 arXiv 补充。
3. 比较题名、作者、年份、期刊/会议和链接；列出冲突而不是强行合并。
4. 将“论文存在”与“论文支持某个主张”分开：前者只需元数据匹配，后者必须有摘要或全文证据。
5. 输出核验记录、风险等级、待人工打开的原文以及可复制的引用。

## 风险等级

- 低风险：两个以上来源元数据一致，主张有可定位原文证据。
- 中风险：论文身份一致但只有摘要/单一来源，不能替代全文核验。
- 高风险：DOI、题名或作者冲突，来源不可访问，或主张无法在记录中定位。

## 禁止事项

- 不因为题名相似就认为是同一篇论文。
- 不把引用次数、搜索排名或 AI 生成摘要当成真实性证明。
- 不隐藏失败来源、访问限制或 DOI 重定向。
