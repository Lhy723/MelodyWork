# Literature Search

## 工作流

1. 明确问题边界：拆出对象、方法、比较对象、结果指标、时间范围和学科范围；无法确定的范围标为待确认。
2. 生成检索计划：给出用户可读的问题改写、精确检索式、同义词表、排除词和可选过滤条件。保留原始白话问题。
3. 分配数据源：优先使用 Crossref、OpenAlex、arXiv、Semantic Scholar、PubMed 等已接通来源；按学科说明来源分工。
4. 执行并记录：保存实际发送的检索词、来源、时间、返回数量和失败来源，不静默丢弃失败请求。
5. 去重和核验：按 DOI 优先、题名次之合并；关键论文至少要求两个独立元数据来源匹配，单一来源显式标注。
6. 交接下一步：把候选结果放入研究收件箱，建议加入文献库、生成知识资产或创建科研追踪主题。

## 输出格式

- 研究问题与范围
- 精确检索式和同义词/排除词
- 数据源表（来源、用途、实际查询、响应状态）
- 结果统计和去重规则
- 下一步行动与需要用户确认的假设

## 质量边界

- 不把搜索结果数量解释成研究结论；数量只代表索引响应。
- 不把摘要、标题或引用次数当成全文审查；需要全文时标记“需打开原文”。
- 对自动翻译的检索词保留原始中文，并展示规范化版本，避免语义漂移。
- 网络或数据源失败时继续使用成功来源，同时报告失败原因。
