# Systematic Review

## 工作流

1. 锁定问题、纳入/排除标准、时间范围和目标人群；把标准写成可检查的规则。
2. 记录检索批次、实际查询、数据源、日期、返回数量和去重方式；保留失败来源。
3. 为每篇候选论文填证据矩阵：研究设计、样本/数据、干预、比较、指标、结果、限制、开放材料。
4. 分开“证据摘要”和“作者解释”，对异质性、偏倚和重复样本进行标记。
5. 输出主题聚类、共识、冲突、证据空白和下一步检索/实验建议，并为每条结论绑定论文 ID。

## 最小证据矩阵

| 字段 | 要求 |
| --- | --- |
| identity | DOI/PMID/arXiv、标题、作者、年份、来源 |
| design | 研究设计、数据集/样本和对照 |
| outcome | 指标、效果量/区间和统计方法 |
| limitations | 作者限制与审核者发现的风险 |
| provenance | 来源记录、全文位置和核验状态 |

## 结论边界

- 综述骨架不是系统综述注册方案；正式注册或统计合并需要额外 protocol 和专业审核。
- 没有全文或可定位结果时，结论只能写成“索引/摘要显示”。
- 证据不足时输出空白和冲突，不用流畅措辞掩盖不确定性。
