# Interior component attribution

`load-more.tsx` is adapted from the Interior component library by ddoemonn,
licensed under the MIT License.

- Project: https://github.com/ddoemonn/interior
- Source: https://www.interior.dev/docs/load-more

The adapter keeps Interior's async sentinel, retry state, end state, and
reduced-motion-aware transitions while using MelodyWork's design tokens and
Chinese labels.
