# Provenance

This directory contains a local adaptation of [Vercel AI Elements](https://github.com/vercel/ai-elements).

The original import did not preserve an upstream commit reference in the
repository history. Recorded comparison anchor (2026-08-13): upstream release
`ai-elements@1.9.0`, commit
[`bc87126`](https://github.com/vercel/ai-elements/commit/bc87126). This is a
comparison baseline, not a claim that the local snapshot is identical. Compare
changes against the upstream repository before upgrading, preserve upstream
license notices, and record the exact upstream commit in this file whenever the
vendored snapshot is refreshed.

Local adaptations include MelodyWork styling, local type boundaries, and
component API changes. The project-level MIT license does not replace any
license obligations that apply to upstream or third-party code. The upstream
snapshot is licensed under Apache-2.0; see the adjacent `LICENSE` file.
